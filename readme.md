# Haskell Functional Programming

## How to run
- `ghci` -> `:l ./file.hs` -> use your file's functions
or
- `ghci file.hs` -> use your file's functions
or
- `runghc file.hs` (load and execute - it requires a main)
```hs
-- main example
  main :: IO ()
  main = do
    print (1+1)
    print (2+2)
    print (3+3)
```
